# October 2026 Development Diary

## Overview

Personal fork work focused on making the existing iOS port buildable from
Windows through GitHub Actions without uploading proprietary game assets.

## 2026-10-14 — Unsigned iOS IPA workflow

- Added an on-demand macOS GitHub Actions workflow for the iOS 16+ device build.
- Added unsigned packaging and IPA output for AltStore/SideStore-style signing.
- Kept retail game assets out of GitHub; the workflow emits only the engine IPA
  and a small public support-files archive for the app Documents directory.
- Preserved the existing signed Xcode/device-install packaging path.
- Pinned CI to a newer vcpkg registry revision after live runs showed that the
  manifest's older built-in baseline predates its FFmpeg 8.1.1#2 override.
- Passed the Vulkan SDK header path into the cross-compiled DXVK build after a
  clean CI runner exposed Meson's otherwise missing `vulkan/vulkan.h` include.
- Initialized DXVK's nested header submodules recursively so native iOS builds
  receive the DirectX, Vulkan, and SPIR-V headers required by the fork.
